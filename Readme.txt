The system is a plant heat stress response gene identification system, Figure 5-1 shows the main interface of the system, the system is a fully open platform, no need to log in. The system is an open platform, and no login is required. After accessing the system, it goes directly to the main interface. From the figure, we can see that the whole system is divided into four parts: home page, frame diagram, prediction, and download.

Individual Sequence Recognition Module
The identification of heat stress-responsive genes is divided into two parts. One is a limited species prediction, including soybean, corn, grape and sorghum, and users need to select the species they want to recognize through the “Species selection” drop-down list, as shown in Figure 5-3. The other is a generalized prediction that applies to all species, as shown in Figure 5-4. Users can paste the gene sequences of plant heat stress response genes into the text box and input them according to the format shown in “Example”, the input sequences must be protein sequences and contain only 20 standard amino acids, DNA or RNA sequences are invalid. Click the “Submit” button to start the prediction.

Batch Sequence Recognition Module
In addition to the use of single pick sequence identification, the system also provides the identification of heat stress response genes in bulk by importing files, but the file format must be .fasta file format. The file selection is done through the “Import File” button in Figure 5-3 and Figure 5-4. Unlike single sequences, the fasta files uploaded by the user will be processed in batches in parallel, and it is recommended that the maximum number of uploaded sequences should not exceed 100 in order to ensure the speed and efficiency of the model.

Regarding the identification of plant heat stress responsive genes, in addition to building an identification system, this paper also provides the download of experimental data. In addition to that, it can be accessed https://github.com/liudalian0524/TranNas_ECD to get the experimental data and models.
